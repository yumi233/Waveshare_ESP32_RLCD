# 400×300 单色界面重构

## 方向

整套页面采用原创的像素乡村菜单风格：深色页眉小木牌、少量像素角饰与留白清楚的信息区。借鉴温暖的农场游戏氛围，不使用《星露谷物语》的原始图像或 UI 素材。为适应 400×300 单色屏，内容区只保留必要的分隔线，不叠加重复窗框、双线和实心栏目牌。保留固定页码、公开版原创 80×80 单色头像、音符与小爱心。开屏页使用同一头像和“夏柠”标题，页眉、语音浮层与配网页面统一使用“夏柠”名称。动态内容直接排在白底上，避免旧底图与实时文字重叠。所有装饰由纯黑白实心像素组成，单色屏不使用灰阶、抖动或细碎背景纹理。

## 五页信息结构

| 页面 | 主要信息 | 次要信息 |
| --- | --- | --- |
| 首页 | Agent 状态、当前任务 | 波奇酱头像、可选额度、音乐 |
| 性能 | CPU / 内存 / GPU / 磁盘占用 | 温度、延迟、上传下载和走势图 |
| 夏柠 | 最近一轮对话 | 今日待办、API 余额 |
| 电脑 | 当前选中的设备 | 发现列表、在线状态和按键提示 |
| 关于 | 原作者黑沐、界面重构者玉米 | 原项目链接、MIT 与第三方许可提示 |

首页继续支持“5 小时与周额度”“任务与周额度”“仅任务”三种模式。页面切换、电脑选择、Reporter 数据和语音浮层沿用现有功能。

## 署名与许可

关于页和 README 区分原项目作者与本地定制者，不把原作者版权转移给重构者。根目录 `LICENSE` 中原有 MIT 版权声明不变；`THIRD_PARTY_NOTICES.md` 保留底座、字体及其他组件的许可证。用户提供的角色参考图及其衍生头像不自动获得 MIT 授权，公开发布前应单独核实素材权利。

## 验收

- 五页在 400×300 逻辑分辨率下没有越界、遮挡和旧底图残留。
- 首页三种模式、音乐播放、性能数据、对话、待办和电脑选择仍能更新。
- 固件应用分区单独刷写，保留已有 Wi-Fi 与其他 NVS 配置。
