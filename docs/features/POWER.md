# POWER-01 · 待机优化

| 改动 | 原行为 | 本版行为 | 代码 |
| --- | --- | --- | --- |
| Reporter 发现 | 约每秒请求 | 约每 5 秒，充值操作后立即刷新 | `reporter_service.cc` |
| LVGL / SPI | 脏区域可能触发多次整帧发送 | 合并至一轮最后一次 flush，像素相同跳过 SPI | `custom_lcd_display.cc` |
| 电池电压 | 状态刷新时重复采集 | 15 秒缓存，每次有效采样仍取多次读数 | `waveshare-s3-rlcd-4.2.cc` |
| Codex 额度 | 反复建立短连接 | 独立长连接、30 秒查询、5 分钟回收 | `reporter/codex_rpc.py`、`reporter.py` |

SPI 优化保留 DMA 完成后通知 LVGL 缓冲区可复用的顺序，没有在 DMA 发送前提前释放。首次帧和实际变化的帧仍会发送。

当前保留待机语音唤醒、麦克风和既有 Wi-Fi 节电策略。没有用强制深睡替代正常语音待机，也没有承诺固定的续航提升比例。

## 如何衡量

在相同电池、Wi-Fi 信号、音量、温度与语音使用频率下对比平均电流或完整放电时长。USB 供电会影响测量，屏幕上的电池百分比来自电压估算，不能直接换算续航。

首页“预计可用天数”仅指宿舍余电，计算来自实际电表历史，不是设备电池续航。
