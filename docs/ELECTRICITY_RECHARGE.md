# 五邑大学余电与充值提醒

标记：ELEC-01（查询）、ELEC-02（充值提醒）、ELEC-03（预计天数）。

macOS Reporter 与 ESP32 RLCD 共享学校生成的一个待支付二维码。Reporter 默认每 5 分钟查询余电；余电小于等于设置阈值时，两端自动显示充值页。默认阈值 10 度、金额 100 元，可改选 50 元。实际付款由用户用微信扫码完成。

## 使用

在 Reporter 状态窗口点击「电费 / 充值」，填写楼栋、房间和提醒阈值并保存。等余额更新后，可生成指定金额的充值码。设备配网页里的楼栋、房间必须与 Reporter 一致；不一致时不会显示其他房间的充值码。Reporter 要在同一局域网运行。

设备首页显示余电与预计天数。用 KEY 切到「宿舍余电」页，按 BOOT 打开充值页。充值页中 KEY 切换选项，BOOT 确认，长按 KEY 关闭。低电量时自动弹出。电脑端支持相同金额和支付结果查询。

充值码有效期由学校返回，目前为 5 分钟。过期码自动隐藏，重新选择金额生成。选择「稍后再付」后，本次低电量提醒停止；余电恢复到阈值以上 2 度后，下一次低电量重新提醒。已支付订单会隐藏二维码，并等待余电到账；不会因到账延迟连续创建自动订单。修改金额会显示新订单，之前的学校二维码不保证作废，请只支付选定的一张。

## 实现与数据

学校入口：[学生宿舍充电指引](https://www.wyu.edu.cn/zwc/info/1416/3911.htm)、[学校充值页面](http://202.192.240.231/recharge.html#/)。接口依据学校页面当前前端代码核验。

- `getCurrentRemaining_v2`：查询余电。
- `create-order-cb`：创建未支付订单；金额以分传入，仅允许 50 或 100 元。
- `check-order-cb`：查询支付结果。

未接入扣款、免密支付或支付凭据。学校接口不稳定时显示缓存/失败，失效或无法确认的新二维码不会继续展示。Reporter 关闭时，设备仍独立查询余电，但充值需要电脑在线。

电脑的房间、阈值保存在本机私有 `reporter.json` 的 `electricity` 字段，设备房间保存在自身 NVS 中，公开示例不包含个人宿舍数据。设备通过已绑定 Reporter 的发现响应获取订单，并用短期本地命令令牌请求切换金额、查询或关闭提醒。配置修改仅允许电脑本机调用。

## 预计可用天数

设备首页、宿舍余电页和 Reporter 状态窗口显示预计可用天数。按「剩余电量 ÷ 实测日均用电」计算，只估算宿舍用电。首次需要至少 24 小时的有效记录，期间显示「预计天数统计中」；不使用虚构的默认日耗电。

Reporter 保存最近 7 天的累计电表读数，形成滚动平均；记录只保存在本机私有 `electricity-history.json`（权限 600），不会随项目发布。设备也独立保存每日基线，即使电脑不在线也能学习日耗电；电脑在线并有有效估算时优先显示电脑的结果。更换宿舍或电表累计读数重置时重新统计。充值通过增加剩余电量更新预计天数，不会被误算为负用电。

## 本次待机优化

- Reporter 发现请求由每秒一次降到每 5 秒一次；操作后立即获取新订单。
- LVGL 多个脏区域合并成一帧，像素完全相同的帧跳过 SPI 发送；保留 DMA 完成后释放缓冲的时序。
- 电池 ADC 采样从每次状态刷新改成每 15 秒缓存一次。
- 保持现有 Wi-Fi 节电、语音唤醒与录音处理。未用强制休眠关闭麦克风。

这些改动减少后台工作，实际电流和电池续航仍需在脱离 USB 后测量。电池百分比是电压估算，不能直接用作功耗测量。

## 验证

本轮 Reporter 共运行 85 项单元与回归测试（77 项通过，8 项因平台条件或端口占用跳过），macOS Swift 类型检查、模拟器构建及 UI / 按键 / 额度主机测试通过。2026-10-10 曾通过 ESP32-S3 固件编译，并对设备日耗电算法验证 8 个边界场景。CoreImage 成功解码电脑和 RLCD 的 225 字节示意二维码。学校 100 元、50 元待支付码已验证，未完成实际付款。低电量、过期、已支付、配置切换和失败场景由模拟测试覆盖。

USB 实机验证（2026-10-10）：完整 16MB 旧固件已备份，分区表和语音资源与旧版一致。写入新应用及 OTA 启动信息后，esptool 校验通过；串口确认联网、音频与唤醒初始化，未发现崩溃或看门狗复位。Reporter 重新收到开发板发现请求。实际持续续航和学校支付到账仍待使用中确认。

## 首次配置与平台范围

公开源码的宿舍默认未设置。设备设置页填写楼栋和房间，在 Mac「电费 / 充值」中填写相同值并保存；阈值默认 10 度。电脑约 5 分钟查询一次，设备独立查询约 15 分钟一次。Windows 共用用电后端，但本版尚未提供图形充值 / 配置窗口或新的 Windows 安装包验收。
